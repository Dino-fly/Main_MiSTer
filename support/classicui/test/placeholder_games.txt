# Placeholder library for the interactive viewer (support/classicui/test/play.sh).
#
# Format:  <games dir>|<rom filename>
#
# Names follow the No-Intro / Redump conventions that the libretro thumbnail server
# keys covers on: a leading article moves after the title ("Legend of Zelda, The"),
# " - " separates a subtitle, and the region goes in parentheses. That is what makes
# these usable for testing lazy cover loading - with classicui_artfetch on, the
# fetcher should resolve most of them against thumbnails.libretro.com.
#
# They are correct for the large majority of these titles but are NOT verified
# against the actual DATs, so the odd cover will not resolve. That is a name
# mismatch, not a loader bug.
#
# Every file is an empty placeholder: nothing here can actually be played.
